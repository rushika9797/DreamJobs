# DreamJobs

## Features
For Job Seekers
- User registration and login
- Profile creation with skills, education, and experience
- Job search and filtering for Recruiters

For Recruiters
- Recruiter registration and authentication
- Job posting and editing
- Viewing and managing candidate applications General Features

General Features
- Secure authentication system
- Role-based access (Admin, Recruiter, Job Seeker)
- Responsive and user-friendly interface
- Open-source codebase for community contribution

## How to Run
1. Clone the repo
2. Install requirements
3. Run `python manage.py runserver`
